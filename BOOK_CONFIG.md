# Book Configuration - Building Sensory AI

## Book Identity
- **Title**: Building Sensory AI: Machine Perception of the Physical World
- **Subtitle**: From Physical Signals to Perceiving, Fusing, and Deploying Machines
- **Series**: Hands-On AI Science Series
- **Author**: Alexander Apartsin
- **First Edition**: 2026
- **Target Audience**: advanced undergraduates, graduate students, and researchers/engineers building AI on real sensors (IoT, wearables, robotics, autonomous systems, industrial monitoring, medical devices)
- **Structure**: 14 parts, 72 chapters, 505 sections, 72 labs, capstone
- **Level tags**: [F] foundational, [C] core, [A] advanced, [R] research frontier (per chapter and section)

## Path Rules
- Content layout: `part-N-slug/module-NN-slug/section-N.M.html` (house convention, matching the Building Vision AI book; directories use `module-NN` so the book-skills `part-*/module-*/section-*.html` globs match, while prose uses Part > Chapter > Section)
- Part landing: `part-N-slug/index.html`  ·  Chapter landing: `part-N-slug/module-NN-slug/index.html`  ·  Sections live directly in the module dir (no `sections/` subdir), named `section-<id>.html` with a dot (e.g. `section-1.1.html`), 2 levels below root (`../../` to root)
- Shared stylesheet: `styles/book.css` (link with the correct relative depth; no inline `<style>` blocks except minimal page overrides)
- Math via KaTeX (`vendor/katex/`); syntax highlighting via Prism (`vendor/prism/`)
- Illustrations: `images/` (raster PNG, referenced from prose)
- The book hierarchy is Part > Chapter > Section. Do not use course/syllabus/module/lecture terminology in prose.
- Regenerate this tree and the machine-readable map with `python scripts/scaffold.py` (parses `building_sensory_ai_book_plan.md`, the plan of record).

## Visual Style
- 15-type callout system from `styles/book.css` (big-picture, key-insight, note, warning, practical-example, fun-note, research-frontier, algorithm, tip, exercise, key-takeaway, library-shortcut, pathway, self-check, lab)
- Running threads to weave across chapters: leakage-safe evaluation, uncertainty/calibration, sensor failure modes, biometric/privacy ethics, the classical-vs-foundation-model tradeoff
- "Right Tool" principle: every from-scratch concept pairs with a `library-shortcut` callout showing the same task in a few lines with a modern library, stating the line-count reduction
