## Per-pass results

### Pass 1: Deduplication
- Ran `scripts/detect_duplicates.py --book-root E:/Projects/Books/SensorAI` (the
  canonical O(n^2) detector). At book scale (505 sections, 16,129 blocks) it is
  impractically slow and its raw output is dominated by boilerplate: two identical
  blocks (the footer title line and the copyright line) appear in all 505 sections,
  producing 254,520 footer-only pairs, a 146 MB report that is 99.6% site chrome.
- `scripts/dedup_report.json` was therefore regenerated with a shingle-prefiltered
  equivalent (same normalize + `SequenceMatcher` >= 0.55 semantics) that excludes
  site-chrome blocks appearing verbatim in more than 20 sections, so the pair list
  reflects content rather than the shared footer. Result: 1,049 content pairs at
  similarity >= 0.55, in three buckets:
  - 712 shared callout/label/quiz template phrasing ("Real-World Application: ...",
    "In Practice: ...", "The Right Tool: ...", self-check "Give the N conditions ...")
    heading substantively different examples in different chapters.
  - ~314 canonical bibliography citations correctly reused across the chapters that
    draw on them (MOMENT, Kalman 1960, TimesFM, Datasheets for Datasets, Scaling
    Wearable Foundation Models, Heusel FID, SciPy, etc.). Multi-chapter citation of a
    foundational work is correct scholarship, not duplication.
  - 23 longer-prose pairs, each reviewed individually: intentional epigraph motifs in
    the AI-agent voice (49.7 vs 9.5, 13.6 vs 26.1); self-check/exercise questions
    probing one concept in two chapter contexts (48.2 vs 33.3, 15.6 vs 17.3, 21.1 vs
    21.2, 16.7 vs 46.7, 31.7 vs 32.7, 39.2 vs 39.7, and the 1.1 vs 1.2 inverse-problem
    prompt the 2026-07-14 audit already flagged as intentional depth reinforcement);
    parallel technique framing on different substance ("magnitude and time warping"
    13.5 vs 17.2, "the library owns the plumbing, you own the one decision" 13.5 vs
    14.5, "the snippet above is deliberately explicit" 5.2 vs 65.6); and shared
    lab-setup boilerplate ("Tools. Python with NumPy, SciPy, Matplotlib..." 2.3 vs
    4.2, 3.6 vs 4.2, 2.6 vs 3.5).
- Resolution for every pair: SKIP (intentional depth progression, functional
  boilerplate, or correct multi-chapter citation). 0 MERGE, 0 CONSOLIDATE, 0
  DIFFERENTIATE. No genuine cross-section content duplication exists.

## Underperformers and prompt-sharpening recommendations

This run was verification-dominant: the manuscript was already clean, so most passes
correctly made zero edits. "Underperformance" is therefore measured as the gap between
tasks surfaced and tasks actioned, and as churn risk, not as missed defects.

- Pack with the most skipped tasks: **Pass 1 (Deduplication)**. Raw, it surfaced
  255,561 candidate pairs (1,049 after excluding the ubiquitous footer) and actioned 0
  (all SKIP). This is by far the largest surfaced-to-actioned gap in the run. The
  cause is a signal-to-noise problem, not a missed duplication: a raw 0.55 char-level
  threshold over unstripped blocks is dominated by the shared footer replicated across
  all 505 sections, correctly-reused bibliography entries, and callout-label template
  phrasing.

- Pack with the most edits per file (over-engineering risk): **Pass 3 (Epigraph)**,
  which touched 72 files. In this run every one of those edits was a genuine
  missing-epigraph fix, so no over-engineering occurred, but Pass 3 is the only
  high-volume writer in the pack and is the one to watch: if the index pages are ever
  regenerated by the content pipeline, hand-written epigraphs must be preserved rather
  than overwritten. No other pass edited more than one file (Pass 5 fixed one en-dash).

### Suggested prompt improvements for the top 2 underperformers

1. **Pass 1 (Dedup).** Two fixes. (a) Tooling: the detector is pure-Python O(n^2) over
   16k blocks and is very slow at book scale; add a length-band or token-shingle
   prefilter so only plausible candidates reach `SequenceMatcher`. (b) Prompt: "Before
   computing similarity, strip the site footer, the prerequisites block, and every
   `bib-entry`/`bib-ref` from consideration, and strip the leading callout-label prefix
   ('Real-World Application:', 'In Practice:', 'The Right Tool:', 'Self-Check', etc.)
   from each block. Treat any surviving pair whose only overlap is a shared label
   prefix, a shared equation, or shared lab-setup boilerplate as SKIP. Require a
   reviewer to confirm at least two consecutive shared sentences of body prose before
   proposing any MERGE or CONSOLIDATE. Multi-chapter citation of the same canonical
   reference is correct scholarship and must never be flagged."

2. **Pass 4 (Bibliography).** The "sort by year descending" rule conflicts with the
   book's intentional thematic-category bibliographies and, applied literally, would
   degrade all 72 of them. Change the prompt to: "Bibliographies may be grouped into
   thematic categories; preserve the category grouping and per-entry annotations. Sort
   entries by year descending only within each category. Completeness (author, year,
   title, venue), truncation repair, and de-duplication are the mandatory checks; a
   flat cross-category year sort is prohibited when category labels are present."
